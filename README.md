## IoT-Assisted Digital Twin: Building Administration, Control, & Monitoring Solution

## Overview

This Unity project presents a proof of concept for a digital twin of **Bliss Hall**. The goal is to create an interactive and immersive simulation that supports both educational use and operational insight.

The project also includes a virtual communication component that allows multiple users to join the same environment, navigate the space together, and communicate in real time.

## Objective

The primary objective is to enhance user engagement and understanding by providing a virtual representation that reflects the real-world environmental and operational state of the physical Bliss Hall building. This includes simulating lecture sessions and other building and academic activities in a realistic and dynamic manner, while enabling shared exploration and interaction among users.
